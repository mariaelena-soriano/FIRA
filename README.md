# FIRA — Facultad de Ingeniería, Realidad Aumentada

## AR Campus FI

**Proyecto final de Realidad Aumentada | Facultad de Ingeniería, UNAM**

AR Campus FI es una aplicación móvil de realidad aumentada desarrollada en Unity y Vuforia, cuyo propósito es ofrecer una experiencia interactiva para explorar espacios representativos de la Facultad de Ingeniería de la Universidad Nacional Autónoma de México.

La aplicación permite seleccionar el Conjunto Norte o el Conjunto Sur, reconocer sus respectivos croquis mediante la cámara del dispositivo y visualizar elementos tridimensionales acompañados de fichas informativas.

## Características principales

- Selección interactiva entre Conjunto Norte y Conjunto Sur.
- Reconocimiento de imágenes mediante Vuforia Engine.
- Visualización de modelos tridimensionales de bibliotecas y auditorios.
- Consulta de fichas informativas.
- Interfaz gráfica desarrollada en Unity.
- Implementación de scripts en C#.
- Desarrollo orientado a dispositivos móviles iOS y Android.

## Tecnologías utilizadas

- Unity 2022.3.62f3.
- Vuforia Engine 11.4.4.
- C#.
- Xcode para la compilación iOS.
- Git y GitHub para el control de versiones.

## Estructura del proyecto

El repositorio contiene los recursos, las configuraciones y las dependencias necesarias para el desarrollo de la aplicación en Unity.

## Estado del proyecto

Prototipo funcional con escenas interactivas, reconocimiento de croquis y visualización de contenidos en realidad aumentada. La integración de recursos multimedia adicionales se contempla como una futura ampliación.
